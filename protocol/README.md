# Protocol artifacts

* `../docs/architecture/PROTOCOL.md` — normative OMP/1 specification.
* `vectors/` — machine-readable golden vectors shared by the Rust core and the C++ firmware.
  Generated by `cargo run -p openmesh-core --example gen_vectors`; CI fails if they drift.

Every vector file is JSON with `{"description": ..., "cases": [...]}`. Implementations MUST
reproduce the expected outputs byte-for-byte; a failing vector is a protocol bug, not a test bug.
