# Code of Conduct

Be decent. This project welcomes contributors of any background and experience level.

Expected behaviour: assume good faith, critique ideas not people, keep discussions technical,
respect privacy (do not publish others' locations, identities or messages), and help newcomers.

Unacceptable behaviour: harassment, discrimination, doxxing, sharing private mesh data without
consent, or using the project to build surveillance or jamming tooling.

Enforcement: maintainers may warn, edit or remove contributions and ban repeat offenders.
Report concerns privately via the contact in `SECURITY.md`.
